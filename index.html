TradingView ka Pine Script (v5/v6) seedha paste karo (//@version=5 aur indicator(...) wala) aur Run dabao, ya apna JavaScript likho (candles, sma(), ema(), rsi() milte hain, return karo array ya { 'Naam': array }).
